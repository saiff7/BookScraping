# BookScraping
📚 Book Scraping Project
A Python-based web scraping project designed to collect and analyze book data from an online bookstore. The goal is to extract details such as book titles, prices, availability, and ratings, and then perform exploratory data analysis (EDA) and visualization.

🔍 Features
Scrapes book information from all category pages.

Extracts:

Title

Price

Rating

Availability

Saves data to a clean CSV format.

Includes visualizations like price distribution, availability comparison, and rating breakdown.

Performs basic data cleaning and transformation.

🛠️ Tech Stack
Python

Libraries:

requests

BeautifulSoup

pandas

matplotlib / seaborn
